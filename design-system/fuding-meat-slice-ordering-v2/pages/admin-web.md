# Merchant Web Override

- Canvas: `#F4F1EB`; surfaces: `#FFFCF7`; text: `#2A211C`; border: `#E4DDD2`.
- Sidebar is 240px on desktop. Content max width is 1440px; tables may use full available width.
- Use a 12-column grid for dashboard metrics, then ordinary sections for operational lists.
- Page titles are 28-32px, card titles 16-18px, body 14-16px. Avoid landing-page hero typography.
- Order cards prioritize pickup number, state and items. Monetary and coupon sources are visually distinct.
- Use inline validation for normal errors and dialogs only for destructive or irreversible actions.
- Keep filters sticky within the content area when useful; never hide table actions behind hover-only controls.
- Mobile tables become stacked cards. Do not force horizontal scrolling for core order and product actions.
- New-order sound and notification controls must state their real browser limitations in plain Chinese.
